# 🧠 Training a Neural Network using TensorFlow on MNIST Dataset

## 📍 Overview
This project demonstrates how to build and train a simple **Neural Network** using **TensorFlow 2.0** and **Keras** to classify handwritten digits from the **MNIST dataset**.

The MNIST dataset consists of **70,000 grayscale images** (28x28 pixels) of handwritten digits (0–9).  
Our neural network learns to recognize these digits with impressive accuracy.

---

## ⚙️ Key Features
- 🔹 **TensorFlow 2.0**: Simplified, beginner-friendly API with eager execution  
- 🔹 **Keras** as the high-level API for model building  
- 🔹 **Data preprocessing** (normalization & one-hot encoding)  
- 🔹 **Fully connected neural network (Dense layers)**  
- 🔹 **Model training and evaluation** on test data  

---

## 🧩 What You’ll Learn
- How to prepare image data for neural network input  
- How to create a deep learning model using the **Sequential API**  
- How to compile and train models with **Adam optimizer**  
- How to evaluate model performance using test accuracy
